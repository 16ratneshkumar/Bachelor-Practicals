# Digital Image Processing - Practicals

![Course](https://img.shields.io/badge/Course-DIP-blue.svg?style=for-the-badge)

Welcome to the collection of practical assignments for the **Digital Image Processing** course. This repository contains implementations using Python and libraries like OpenCV and Scikit-Image.

---

## 🛠️ Environment Setup

This project uses **Python**. We recommend using Jupyter Notebook or any standard Python IDE.

**Quick Setup:**
1.  **Install Python:** Download and install from [python.org](https://www.python.org/).
2.  **Install Libraries:** Install the required libraries using pip:
    ```bash
    pip install opencv-python scikit-image numpy matplotlib scipy
    ```
3.  **Run Scripts:** Open the terminal in this directory and run:
    ```bash
    python filename.py
    ```

---

## 📅 List of Practicals

This repository covers the following practicals:

1.  **[Basic Image Operations](./practical1.py)**
    - a. Read and display image
    - b. Resize a given image
    - c. Convert a given color image into a corresponding gray-scale image
    - d. Convert a given color/gray-scale image into black & white image and draw the image profile
    - e. Separate a given color image into three R, G & B planes
    - f. Create a color image using separate three R, G and B planes
    - g. Write given 2-D data in image file
2.  **[Point Processing Methods](./practical2.py)**
    - a. Obtain negative image
    - b. Obtain flip image
    - c. Thresholding
    - d. Contrast stretching
3.  **[Image Arithmetic Operations](./practical3.py)**
    - a. Addition of two images
    - b. Subtract one image from other image
    - c. Calculate mean value of image
    - d. Different brightness by changing mean value
4.  **[Image Logical Operations](./practical4.py)**
    - a. AND operation between two images
    - b. OR operation between two images
    - c. Calculate intersection of two images
    - d. Water marking using X-OR operation
    - e. NOT operation (negative image)
5.  **[Histogram Calculation and Equalization](./practical5.py)**
    - a. Using inbuilt function
    - b. Without using inbuilt function
6.  **[Geometric Transformations](./practical6.py)**
    - a. Translation
    - b. Scaling
    - c. Rotation
    - d. Shrinking
    - e. Zooming
7.  **[Noise Models and Restoration](./practical7.py)**
    - a. Image restoration
    - b. Remove salt and pepper noise
    - c. Minimize Gaussian noise
    - d. Median filter and Wiener filter
8.  **[Spatial Filtering](./practical8.py)**
    - a. Understand 1-D and 2-D convolution process
    - b. Use 3x3 mask for low pass filter and high pass filter
9.  **[Frequency Domain Filtering](./practical9.py)**
    - a. Apply FFT on given image
    - b. Perform low pass and high pass filtering in frequency domain
    - c. Apply IFFT to reconstruct image
10. **[Edge Detection](./practical10.py)**
    - Edge detection using different edge detection mask
11. **[Morphological Operations](./practical11.py)**
    - Image morphological operations: erosion and dilation
